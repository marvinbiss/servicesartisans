## 1. Exec summary — pourquoi ça marche

ServicesArtisans a **3 leviers uniques** vs concurrents pour attirer des backlinks :

1. **Data propriétaire** : baromètre prix réels (leads DB) → aucun concurrent n'a ça publiquement
2. **Intégration ADEME officielle** : 60K SIRET RGE synchronisés → base de données citable
3. **Angle "leads exclusifs vs mutualisés"** : débat légal DGCCRF → angle presse consumer protection

Ces 3 angles ouvrent **3 tiers de backlinks** que les concurrents ne peuvent pas obtenir en volume.
