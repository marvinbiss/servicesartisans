## 11. Bloquants résiduels (non bloquants — intégration propre post-MVP)

### 11.1 Forfait BAR-TH-171 — formule variable

Intégrer la table exacte du PDF DGEC vA78.4 dans le code. Pas de valeur figée possible ici.

```ts
function computeBarTh171(
  zone: 'H1' | 'H2' | 'H3',
  etasClass: 1 | 2,
  surface: number,
  typeLogement: 'maison' | 'appart'
): number
```

### 11.2 Cours kWhc — variable d'environnement

```
CEE_PRIX_CLASSIQUE=8.5   # €/MWhc, refresh trimestriel
CEE_PRIX_PRECARITE=15.0
```

Si variable absente, le simulateur affiche les kWhc et le texte : « Prime estimée selon cours du marché ».

### 11.3 Montants délégataires — fourchette publique, valeur exacte privée

**Simulateur public** : fourchette uniquement.

```ts
const PRIME_FOURCHETTE = {
  bas: kwh_cumac * (CEE_PRIX_CLASSIQUE * 0.85), // −15 % marge négo
  haut: kwh_cumac * CEE_PRIX_PRECARITE,
}
// Affichage : "Entre 3 200 € et 5 400 €"
```

**Back-office mandataire** : valeur exacte au cours du jour. Les deux vues vivent séparément — pas de fuite de la valeur privée vers le public.

### Conclusion

Les 3 points sont non-bloquants. Le code peut démarrer maintenant sur les fondations solides (plafonds ANAH, écrêtement, BAR-TH-148/113/143/127), et les 3 points s'insèrent proprement plus tard sans refactoring.
