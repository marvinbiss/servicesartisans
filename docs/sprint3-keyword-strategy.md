# Sprint 3 — Keyword Strategy & Flagship Pages

**Date** : 2026-04-18
**Objectif** : Passer de 350 clics/j à 2000+ clics/j en 6 mois via 100 pages flagship
sur requêtes à volume + CTR attack sur pSEO existant (Sprint 2 déjà livré).

---

## 1. Constat stratégique (basé sur GSC 2026-04-18)

- **459K pages indexées** → 0.023 clic/page/mois = 20-80× sous la norme
- **Vrai problème** : choix des mots-clés, pas le SEO technique
- Pages rang 1-3 sur des requêtes à **6-10 impressions** (ultra-niche inutile)
- Pages à volume (hub `/tarifs` : 68 impressions/90j) en pos 8 avec CTR 1.5%

**Abandon** :

- Enrichissement pSEO 9.5/10 sur 338K templates
- Stratégie volume d'indexation

**Go** :

- 100 flagship pages sur head/middle-tail (volume 500-5K/mois, diff <40)
- Sprint 2 CTR rewrites sur pages à volume réel (✅ livré)
- Noindex brutal sur 0-impression pages (S3.3)
- Reviews flywheel pour rich snippets ★ (✅ livré, en attente seed)

## 3. Structure Flagship Page (vs pSEO)

### Différences vs templates pSEO actuels

| Aspect             | pSEO template               | Flagship page                              |
| ------------------ | --------------------------- | ------------------------------------------ |
| Word count         | 500-1500                    | 2000-4000                                  |
| Intent             | Couverture large            | Intent spécifique + approfondi             |
| Backlinks internes | Maillage auto               | Curation éditoriale                        |
| E-E-A-T            | Signatures auteur générique | Auteur expert identifié + bio + photo      |
| Data               | Template fill-in            | Data propriétaire (stats, études, graphs)  |
| Schema             | Basic LocalBusiness         | Article + HowTo + FAQPage + BreadcrumbList |
| Images             | Stock génériques            | Photos/schémas originaux + ALT optimisés   |
| Update freq        | Batch (24h ISR)             | Review trimestrielle éditoriale            |

### Template structure

```markdown
# [H1 : Question intent principale]

[Lede (2-3 phrases, 40-60 mots) — répond à l'intent en 1 phrase puis promet
l'article]

## TL;DR (3-5 bullets)

Réponse courte pour featured snippet + AEO + AIO France prep.

## [H2 : Sous-question 1 liée]

Passage 300-500 mots. Repère le mot-clé principal 2-3× naturellement.

### [H3 : Détail spécifique]

Passage 150-250 mots.

## [H2 : Sous-question 2 liée]

...

## Prix & Tarifs [si applicable]

- Tableau prix détaillé avec sources
- CTA : "Demander un devis gratuit" → /devis/[service]/[ville]

## FAQ (5-8 questions)

Format Q/R extractable pour FAQPage schema + People Also Ask.

## Cas pratique / étude / exemple réel

Data propriétaire (anonymisée client). Renforce E-E-A-T "Experience".

## Par région / ville [si applicable]

Liens vers 10-15 pages pSEO locales (maillage outbound).

## Auteur / Sources

Photo auteur + bio + qualifications + date publication + date mise à jour.
Liens vers sources officielles (ADEME, Service-public.fr, Qualibat, etc.).
```

### Schema.org requis

```json
[
  { "@type": "Article", ... },
  { "@type": "FAQPage", ... },
  { "@type": "HowTo", ... },       // si tutoriel
  { "@type": "BreadcrumbList", ... },
  { "@type": "Organization", ... }  // auteur si possible
]
```

## 8. Risques

1. **Volumes surestimés** : la validation Ahrefs/Semrush peut révéler que certains
   clusters sont trop petits. Réserve 10-15% des keywords en buffer.
2. **Google update** : AIO France arrive H2 2026 — certaines requêtes info peuvent
   être directement répondues par Google. Focus sur transactional & commercial
   pour hedge.
3. **Concurrence montante** : IZI by EDF très agressif sur MaPrimeRénov. Angle
   différenciation = leads exclusifs (déjà enforced DB) + baromètre data.
4. **Bus factor** : 1 seul dev. Sprint 1.14 (offre dev senior) encore pending.
