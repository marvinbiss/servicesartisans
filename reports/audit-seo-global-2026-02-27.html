1 Synthese executive

Le present rapport constitue un audit technique exhaustif du referencement naturel du site ServicesArtisans.fr, annuaire d'artisans francais. L'analyse croise les donnees Google Search Console (indexation, crawl, requetes, rich results) avec un audit complet du code source (Next.js 14, TypeScript).

Contexte strategique Le site est en phase de sortie de sandbox Google avec une trajectoire de croissance exponentielle des impressions (x20 en 7 jours). Cette fenetre d'opportunite est critique : les corrections apportees maintenant auront un effet demultiplie sur les 3 prochains mois.

Verdict global

Quatre failles structurelles majeures brident le potentiel du site :

4.3 Probleme identifie — Redirections residuelles

Le middleware redirige correctement /tarifs-artisans vers /tarifs en 301, mais les fichiers legacy src/app/(public)/tarifs-artisans/ existent encore dans le code. Tant qu'ils existent, Next.js les sert comme routes valides avant la redirection, generant un hit supplementaire sur le budget crawl.

Recommandation F5 Supprimer les fichiers /tarifs-artisans/ du codebase. Le middleware gerera la 301 directement, economisant ~1 590 requetes crawl par periode.

5.2 F1 — BreadcrumbList (CRITIQUE)

Defaut F1 : 93% des breadcrumbs invalides Le format JSON-LD utilise dans getBreadcrumbSchema() produit un format que Google Rich Results Test rejette systematiquement.

Fichier concerne : src/lib/seo/jsonld.ts, lignes 159-170

Fichiers impactes : 50 fichiers appellent cette fonction ou le composant <Breadcrumb>

// Code actuel (DEFAILLANT)
export function getBreadcrumbSchema(items) {
  return {
    '@type': 'BreadcrumbList',
    itemListElement: items.map((item, index) => ({
      '@type': 'ListItem',
      position: index + 1,
      name: item.name,
      item: `${SITE_URL}${item.url}`,  // Format non optimal pour Google
    })),
  }
}

Impact CTR estime : +0.5 a +1% de CTR une fois corrige (breadcrumbs visibles dans les SERPs).

5.3 F2 — Review Schema (HAUTE)

Defaut F2 : 10/11 reviews rejetees Les objets Review imbriques dans LocalBusiness.review n'ont pas de propriete itemReviewed.

Fichier concerne : src/components/artisan/ArtisanSchema.tsx, lignes 123-137

Problemes identifies :

  • Missing itemReviewed sur tous les Review objects
  • datePublished potentiellement null (via r.dateISO || r.date)
  • worstRating inconsistant entre les implementations

Impact CTR estime : +1 a +3% de CTR (etoiles dans les SERPs = signal visuel puissant).

5.4 ProfilePage — Deploiement limite

Le schema ProfilePage n'est genere que dans ArtisanSchema.tsx, rendu uniquement sur les pages provider detail. Avec seulement quelques artisans ayant des fiches completes, seuls 4 ProfilePage sont detectes. Impact faible a ce stade.

7.3 Analyse du CTR

Le CTR de 0.32% s'explique par deux facteurs :

  1. Position moyenne 42 — les pages sont majoritairement en page 4-5 de Google, ou le CTR naturel est <0.5%
  2. Absence de rich results — sans breadcrumbs ni etoiles visibles, les snippets n'attirent pas l'attention
Projection Avec la correction des rich results (F1 + F2) et la progression naturelle des positions (sortie sandbox), le CTR devrait atteindre 1-2% dans les 3 mois, et 2-4% a 6 mois si les positions progressent en page 1-2.

10 Plan d'action et feuille de route

Semaine 1 — Actions immediates
F1 : Corriger getBreadcrumbSchema()
Modifier src/lib/seo/jsonld.ts pour produire un format compatible Google Rich Results. Impact : breadcrumbs visibles dans les SERPs sur 9 310+ pages.
Semaine 1
F2 : Corriger ArtisanSchema.tsx
Ajouter itemReviewed a tous les Review objects. Securiser datePublished. Impact : etoiles dans les SERPs.
Semaine 1
F5 : Supprimer /tarifs-artisans/
Supprimer les fichiers legacy. Le middleware gere deja la 301. Economie : ~1 590 requetes crawl/periode.
Semaine 2-3 — Court terme
F3 : Ajouter rel="nofollow" sur liens footer legaux
Appliquer nofollow sur /politique-avis, /faq, /mediation, /cgv, /mentions-legales, /confidentialite, /accessibilite dans Footer.tsx.
Semaine 2-3
F4 : Ajouter cross-links symetriques
Creer un composant CrossLinks reutilisable pour les pages /devis/, /avis/, /tarifs/ qui lie vers /services/ et entre elles.
Mois 2-3 — Quand indexation > 50%
F6 : Activer Phase 2 du sitemap
Decommenter service-cities-extended dans generateSitemaps(). Ajoute ~90 000 URLs.
Mois 2-3
F7 : Enrichir meta descriptions quartier
Varier les templates de description pour les pages /devis/[service]/[location]/[quartier].
