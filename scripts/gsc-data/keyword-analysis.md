## 7. Recommandations Strategiques

### 7.1 Quick Wins (effort faible, impact fort)

- **Articles #5 (tarif horaire artisan)** : Page synthetique avec tableau comparatif de TOUS les metiers. Cible la requete generique "tarif artisan" qui capte du trafic pour tous les metiers. Featured snippet potentiel avec un tableau bien structure.

- **Articles #6 et #7** : Intent informationnel pur, facile a ecrire, fort potentiel PAA/featured snippet.

### 7.2 Content Clusters a Renforcer

Le site est deja fort sur les **prix par metier** mais manque les **prix par type de projet** :
- Construction maison neuve
- Piscine
- Refection toiture complete
- Isolation exterieure (ITE)
- Assainissement (micro station)

### 7.3 Schema FAQ / Structured Data

Chaque nouvel article devrait inclure un bloc FAQ (deja supporte par l'interface BlogArticle avec `faq`), ciblant les PAA identifiees dans cette analyse. Cela maximise les chances d'apparaitre dans les "People Also Ask" de Google.

### 7.4 Maillage Interne

Les nouveaux articles doivent faire du maillage vers :
- Les pages service correspondantes (`/services/{slug}`)
- Les pages prix existantes (`/tarifs/{slug}`)
- Les articles aides (MaPrimeRenov, CEE, eco-PTZ)
- Les articles urgence quand pertinent

### 7.5 Mise a Jour des Articles Existants

Certains articles existants pourraient beneficier d'une mise a jour pour cibler des PAA specifiques :
- `prix-renovation-maison-2026-budget-complet` : Ajouter FAQ "budget 100m2", "par ou commencer"
- `isolation-maison-guide-complet-materiaux-prix-aides` : Ajouter section ITE specifique
- `prix-toiture-2026-refection-reparation-materiaux` : Ajouter comparatif ardoise vs tuile
