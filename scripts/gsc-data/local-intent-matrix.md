## 9. Insights strategiques

### Ce qui marche deja
- Les pages `/tarifs/` rankent sur l'intent "prix [metier] [ville]" -- **c'est le meilleur vecteur de croissance SEO**
- Les fiches individuelles dans les petites villes (Vesoul, Fourques, Grasse, Athis-Mons) atteignent des positions 1-8
- Le metier "ferronnier" est une niche peu concurrencee ou servicesartisans.fr est deja position 3

### Strategie recommandee
1. **Doubler la mise sur /tarifs/** : creer 30 articles prix x ville (les 30 villes ci-dessus x les 3-4 metiers principaux)
2. **Villes moyennes d'abord** : ne pas gaspiller de ressources sur Paris/Lyon/Marseille en intent transactionnel. Se concentrer sur le Tier 1 (Valence, Besancon, Perpignan, Mulhouse, Lorient)
3. **Niches differenciantes** : climaticien (Perpignan, Aix, Toulon), ferronnier (deja position 3), vitrier/Nimes (deja position 9.5) -- capitaliser sur ces positions existantes
4. **Intent informationnel sur les grandes villes** : les pages prix/tarifs sont viables meme a Paris car la concurrence est sur l'intent transactionnel (annuaires, depannage)
5. **Maillage interne** : lier systematiquement /tarifs/[metier]/[ville] <-> /devis/[metier]/[ville] <-> /services/[metier]/[ville]

### KPIs a suivre
- Nombre de pages /tarifs/ indexees par ville
- Position moyenne sur "prix [metier] [ville]" pour les 30 villes cibles
- Taux de conversion /tarifs/ -> /devis/ (demande de devis)
- Impressions GSC sur les requetes "prix/tarif/devis + ville" filtre villes moyennes
